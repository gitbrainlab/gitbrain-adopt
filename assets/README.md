# Visual patterns (from contract-design practice)

We borrow **comprehension patterns**, not legal content:

| Pattern | Used in this kit |
|---------|------------------|
| Delivery diagram | README + docs/00 — who holds a change until transfer |
| Comparison table | docs/01 terms; README two doors |
| Flowchart | docs/02 programmatic path |
| Swimlane / sequence | docs/00 and docs/03 |
| Companion icons | prompts/README mental model |
| One topic per page | each docs/NN file |

Visuals **complement** text; every diagram has rules underneath.
