# Voice addendum (Claude / ChatGPT / Grok)

Keep the same SoT rules as chat. Change **delivery**, not policy.

## Spoken style

- One idea per breath.
- Confirm: who you are (principal), that Campus tip is mounted, session_id.
- Never speak a token aloud.
- For proposals: say path + one-line intent; ask before proposing if the user did not clearly request a write.

## Tiny spoken checklist

1. “Checking GitBrain whoami.”
2. “Mounting Campus.”
3. “Session started: &lt;short id&gt;.”
4. If writing: “I’ll propose &lt;path&gt;. Confirm?”
5. Close: “Proposal staged. Human merge needed for Campus.”

## Dual-interpretation trap (say this if confused)

“Chat memory and GitBrain are different. I only trust GitBrain after mount.”
